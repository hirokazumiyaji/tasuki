**Goal:** Ship a `cmd/bench` CLI that measures E2E completed-instances/s against memory and PostgreSQL with in-process workers.

**Architecture:** `bench` package owns workload + `Runner`; `cmd/bench` parses flags and opens backends. Workers share one process (Approach A). No engine API changes.

**Tech Stack:** Go workspace (`go.work`), `backend/memory`, `backend/postgres`, existing `tasuki` Client/Worker APIs.

**Spec:** [docs/superpowers/specs/2026-07-24-m5-bench-design.md](../specs/2026-07-24-m5-bench-design.md)

## Global Constraints

- Primary metric: `completed / wall_seconds` (instances/s)
- Backends this slice: `memory`, `postgres` only
- Postgres DSN: `TASUKI_POSTGRES_DSN`; Migrate + Reset before run
- In-process workers only; no multi-process spawn
- Do not change public engine APIs
- Every commit / merge subject includes `[skip ci]`

```go
package bench

import (
	"encoding/json"
	"fmt"
)

type Result struct {
	Backend      string  `json:"backend"`
	Workers      int     `json:"workers"`
	Instances    int     `json:"instances"`
	Steps        int     `json:"steps"`
	Completed    int     `json:"completed"`
	Failed       int     `json:"failed"`
	WallSeconds  float64 `json:"wall_seconds"`
	Throughput   float64 `json:"throughput"`
}

func (r Result) FormatHuman() string {
	return fmt.Sprintf(
		"backend=%s workers=%d instances=%d steps=%d\ncompleted=%d failed=%d wall=%.3fs throughput=%.2f/s\n",
		r.Backend, r.Workers, r.Instances, r.Steps,
		r.Completed, r.Failed, r.WallSeconds, r.Throughput,
	)
}

func (r Result) FormatJSON() ([]byte, error) {
	return json.Marshal(r)
}
```

- [ ] **Step 4: Implement `workload.go`**

```go
package bench

import (
	"context"

	"github.com/hirokazumiyaji/tasuki"
	"github.com/hirokazumiyaji/tasuki/workflow"
)

const (
	WorkflowName = "bench-chain"
	ActivityName = "bench-step"
)

func Register(w *tasuki.Worker) {
	tasuki.RegisterActivity(w, step, tasuki.WithName(ActivityName))
	tasuki.RegisterWorkflow(w, chain, tasuki.WithName(WorkflowName))
}

func chain(ctx *workflow.Context, steps int) (int, error) {
	v := 0
	for i := 0; i < steps; i++ {
		next, err := workflow.Execute[int, int](ctx, ActivityName, v)
		if err != nil {
			return 0, err
		}
		v = next
	}
	return v, nil
}

func step(_ context.Context, n int) (int, error) {
	return n + 1, nil
}
```

- [ ] **Step 5: Implement `runner.go`**

Defaults when zero: Workers=4, Instances=200, Steps=3, Poll=20ms, Lease=30s.

Algorithm:

1. Apply defaults to `cfg`.
2. Create `workers` Workers; each `Register(w)` then `Start(ctx)` with distinct `WorkerID` (`bench-w-%d`).
3. `client := tasuki.NewClient(b)`.
4. `start := time.Now()`.
5. Start `cfg.Instances` workflows: input=`cfg.Steps`, ID=`bench-%d`, name=`WorkflowName`. Collect handles.
6. Wait:
   - If `cfg.Duration == 0`: for each handle, `tasuki.Result[int](ctx, h)`; count completed vs failed.
   - If `cfg.Duration > 0`: `context.WithTimeout`; wait in goroutines; count only successful `Result` before cancel; incomplete do not increment `Failed` unless `Result` returned an error (use separate incomplete — for v1, treat timeout incompletes as neither completed nor failed, or document `Failed` as Result errors only; set `Completed` from successes only).
7. `wall := time.Since(start).Seconds()`; `throughput := float64(completed)/wall` (if wall==0, use tiny epsilon or leave 0).
8. Shutdown all workers with short timeout; return `Result`.

Use `errgroup` or waitgroup for parallel Result waits when Duration==0.
