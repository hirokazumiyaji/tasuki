# M6 Memo Implementation Plan

> Inline execution. One commit + PR per task. Every commit/merge subject includes `[skip ci]`.

**Goal:** Display-only string memos on instances: set at Start, upsert from workflow, visible on Get (no List filter).

**Architecture:** Persist `memo` JSON map on `wf_instances`. Upserts are journal commands (`memo_updated`) whose payload is the **full merged map** after apply; empty string values delete keys. `CommitAdvancement` updates the instance column when such events are present. Mirror search-attributes patterns everywhere except List filtering.

**Spec:** [docs/superpowers/specs/2026-07-28-m6-memo-design.md](../specs/2026-07-28-m6-memo-design.md)

## Notes

### Types (`backend/types.go`)

```go
type NewInstance struct {
	// ...existing...
	Memo map[string]string
}

type Instance struct {
	// ...existing...
	Memo map[string]string
}
```

Do **not** add memo fields to `InstanceFilter`.

Reuse `MergeSearchAttributes` / `CloneSearchAttributes` / `MarshalSearchAttributes` / `SearchAttributesFromPayload` for memo maps (same `map[string]string` semantics), or thin aliases:

```go
// Optional aliases for readability at call sites
func MergeMemo(base, patch map[string]string) map[string]string {
	return MergeSearchAttributes(base, patch)
}
```

Prefer reusing existing helpers without renaming unless call sites become confusing. Add memo-specific journal helpers:

```go
func HasMemoUpdate(events []journal.Event) bool
func LastMemoUpdate(events []journal.Event) map[string]string
```

### Journal (`journal/event.go`)

- `TypeMemoUpdated Type = "memo_updated"`
- `IsCommand() == true`
- Payload: JSON object of the **merged** map (`{}` allowed)

### Workflow (`workflow/memo.go`)

```go
func UpsertMemo(ctx *Context, attrs map[string]string)
func (c *Context) SetMemo(attrs map[string]string)
func (c *Context) Memo() map[string]string
```

- Maintain `ctx.memo map[string]string`
- Seed from journal `memo_updated` in `NewContext`; Worker/Query call `SetMemo(state.Instance.Memo)`
- `recordOrReplay(Command{Type: TypeMemoUpdated}, mergedJSON)` — same pattern as `UpsertSearchAttributes`

### Client (`options.go`, `client.go`)

```go
func WithMemo(attrs map[string]string) StartOption
```

Pass into `CreateInstance` via `NewInstance.Memo` (copy; skip empty values).

### CommitAdvancement (all stores)

After inserting journal events, if any `NewEvents` has `TypeMemoUpdated`, take the **last** such event’s payload and UPDATE `wf_instances.memo`.

### List

Unchanged — do not filter or select memo for matching. Get/LoadWorkflowHead must still **return** Memo when scanning instance rows.

### Schema

| Store | Change |
|---|---|
| postgres / mysql / sqlite | `memo` JSON/JSONB/TEXT NOT NULL DEFAULT `'{}'` + idempotent ALTER |
| spanner | JSON column + migrate ensure |
| dynamodb / firestore | map/JSON field on instance |
| memory | field on in-memory instance |
