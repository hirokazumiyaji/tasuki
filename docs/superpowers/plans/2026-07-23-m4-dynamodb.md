# M4 DynamoDB Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Do **not** use subagents. One commit + one PR per task; merge to `main` before the next.
>
> **CI:** Every commit message AND every merge commit subject MUST include `[skip ci]`.
>
> Merge: `gh pr merge --merge --subject "Merge pull request #N from branch [skip ci]"`

**Goal:** DynamoDB バックエンドを条件付き更新 + TransactWriteItems で実装し、Local 上で適合・カオスをグリーンにする。あわせてエンジンが `Capabilities.MaxAdvancementEffects` を尊重する。

**Architecture:** 独立モジュール `backend/dynamodb`。マルチテーブル。Claim は GSI Query + `visible_at` 条件付き Update。Workflow singleton は PK `WF#<instance_id>`。前進は TransactWriteItems。Capabilities は `MaxAdvancementEffects: 80`。

**Tech Stack:** Go 1.26+、`aws-sdk-go-v2`、`amazon/dynamodb-local`、既存 `backendtest` + `chaos`。

**Spec:** [docs/superpowers/specs/2026-07-23-m4-dynamodb-design.md](../specs/2026-07-23-m4-dynamodb-design.md)

### Key design reminders

- Tables: `tasuki_wf_instances`, `…_journal`, `…_inbox`, `…_tasks`, `…_timers`, `…_schedules` (prefix configurable)
- Task PK: workflow `WF#id`, activity `ACT#<rand>`
- GSI claim: `gsi_pk=kind#queue`, SK=`visible_at` (epoch µs N or fixed RFC3339Nano)
- Env: `TASUKI_DYNAMODB_ENDPOINT`, dummy AWS creds, `AWS_REGION`

### Env

```bash
docker compose up -d dynamodb
export TASUKI_DYNAMODB_ENDPOINT=http://localhost:8000
export AWS_ACCESS_KEY_ID=local AWS_SECRET_ACCESS_KEY=local AWS_REGION=us-east-1
```
